    About treestamp
    
              
    Treestamp turns a Git repository into a curated directory tree for your Markdown documentation. Keep the useful structure, fold the detail, and add short notes.
    
            
    
            
    
              
    Usage guide
    
              
      
                
    1. 
                  
      Load a repository
      
                  
      Enter a public GitHub repository URL to capture its default-branch HEAD, or try a bundled offline example. Choose a subtree or open an existing treestamp document. Paths start at the repository root.
      
                
      2. 
                
    2. 
                  
      Curate your tree
      
                  
      Expand or fold folders, hide entries, and add single-line notes. Your session uses a frozen snapshot. A failed load or edit keeps your previous draft.
      
                
      3. 
                
    3. 
                  
      Copy into your docs
      
                  
      Copy the treestamp block into Markdown. Install the treestamp command locally to refresh it as your repository changes, including with local or unpublished commits.
      
                
      4. 
              
    
            
    
            
    
              
    Privacy notice
    
              
    Repository data is cached temporarily. Traffic data is used only for security and basic service operations, and is not sold or shared. There is no additional third-party tracking, and visitors' GitHub account information is not accessed.
    
            
    
            
    
              
    Contributing
    
              
    Report bugs or propose changes on GitHub. Report security issues through private vulnerability reporting, and conduct concerns to conduct@reponomics.org.

    Keyboard shortcuts
    
      
    
    
    
    
    Enable TUI-mode and focus a tree row to use these keys. Shortcuts pause while you type in a field or use a dialog.
    
    
    Navigation
    
    
    
      
    ↑ ↓
    Previous / next visible row
    
      
    ←
    Collapse folder or go to parent
    
      
    →
    Expand folder or go to first child
    
      
    Home End
    First / last visible row
    
      
    Page Up Page Down
    Move up / down one page
    
      
    Space
    Expand / collapse folder
    
    
    
    
    Editing and settings
    
    
    
      
    a
    Open Note
    
      
    h
    Hide / show selected entry
    
      
    Shift + H
    Toggle Reveal hidden entries
    
      
    Shift + S
    Unhide all entries in the treestamp
    
      
    f
    Toggle counts on or off
    
      
    ?
    Open this key map
    
    
    
    
    In Note, press Enter to apply or Esc to cancel. All actions are also available through the buttons and settings.
