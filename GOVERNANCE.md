# Governance

Treestamp is owned by the [Reponomics](https://github.com/reponomics) GitHub organization and maintained by one person.

## Members and access

| Member | Role | Access to sensitive resources |
| --- | --- | --- |
| [@hesreallyhim](https://github.com/hesreallyhim) | Maintainer | Repository and organization administration, repository secrets and environments, the Release Please GitHub App, the hosted editor's GitHub API credentials, the PyPI project, the Fly.io apps, and the `reponomics.org` Cloudflare zone |

No other person has access to these resources. Organization membership alone grants read access to this public repository and confers no other privileges.

## Roles and responsibilities

The maintainer:

- reviews and merges pull requests, and sets the project's direction and scope
- triages issues, discussions, and private vulnerability reports according to [SECURITY.md](.github/SECURITY.md)
- approves releases by merging Release Please pull requests, and oversees PyPI publication and deployment of the hosted editor
- manages repository settings, rulesets, secrets, and credentials for the services listed above
- maintains the project's documentation, including this file

Contributors propose changes through issues and pull requests, following [CONTRIBUTING](.github/CONTRIBUTING.md) and the [code of conduct](.github/CODE_OF_CONDUCT.md). Contributing does not grant write access or access to sensitive resources.

## Decisions and changes to access

The maintainer makes project decisions, discussing significant changes in public issues or discussions before adopting them. Access to the resources above is granted only by the maintainer and is recorded in this file when it changes.
