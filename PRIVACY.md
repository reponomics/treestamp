# Privacy

This project is committed to respecting the privacy of its users, including consumers of the CLI/TUI, and users of the web-editor.

## CLI/TUI

The Python package does not contain any telemetry, and does not make any network requests.

## Web Editor

Repository data is cached temporarily. This includes directory structure and filenames; contents are read only when a user loads a treestamp from a repo document; contents outside of the treestamp boundary markers is not persisted Traffic data is used only for security and basic service operations, and is not sold or shared. There is no additional third-party tracking, and visitors' GitHub account information is not accessed.

The application does not deal with authorization at all. All data accessed by the web editor is publicly available data from GitHub. No assumption is made about the relationship between the user and the repository that they have entered into the web editor interface.
